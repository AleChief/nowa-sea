## 1. Что NOWA делает и чего не делает

- Это когнитивное ядро на Python (только стандартная библиотека). Нейросети с вектором весов нет: внутри каналы
  действий, контекстные токены, Q-значения, Go/NoGo, аффект из 8 осей, гиппокамп, кора, нейромодуляторы,
  геном и эпигеном.
- **Агент выбирает дискретное действие-намерение** из зарегистрированных каналов. Движение, физика, анимация,
  восприятие мира — забота хоста.
- Обучение двухуровневое:
  - днём пишется только лабильный слой (быстрые затухающие смещения Q и Go/NoGo);
  - устойчивая память меняется **только** в `agent.sleep()`.

  Без сна агент не учится надолго.

## 2. Контракт хоста

### Создание агента

```python
hip = NOWAHippocampus(max_experiences=N, activation_similarity_threshold=0.6)
cortex = CortexMemory()
selector = ActionSelector(actions=[...])          # каналы действий вида
intent = IntentMemory()
sleep = SleepManager(hip, cortex, intent_memory=intent)
agent = Agent(hip, cortex, selector, sleep_manager=sleep, intent_memory=intent,
              rng_seed=seed,
              plasticity_config=PlasticityConfig(expected_wake_interval_s=T_wake))
```

- `expected_wake_interval_s` задаётся в тех же единицах времени, что и `dt`, — в среднем бодрствовании между снами.
  Если не задать, ядро предупредит и возьмёт 3600 с.
- Новый канал действия после создания добавляется через `agent.register_action_channel(id)`. Ручная начинка
  устойчивой памяти — только внутри `with initializing():`.

### Решение и исход (паттерн демо-колонии)

```python
action = agent.step(context_events=tokens, reward=None, novelty=..., conflict=..., intensity=...,
                    decision_only=True, physiological_bias=..., dt=dt)
executed = motor_layer_resolve(action)   # хост может переопределить решение
agent.commit_executed_transition(action=executed, reward=r, context_events=tokens,
                                 decided_action=action, overridden=(executed != action),
                                 override_source="...")
```

- `dt` передаётся **всегда**, иначе ядро берёт настенные часы. Его передаёт `step`. `commit` после `step` идёт
  без `dt`, чтобы тик не посчитался дважды. На тиках без решения время двигает `agent.advance_time(dt)`.
- `reward`: `NaN` значит «неизвестно», и запись не делается; `±inf` превращается в `±1`.
- `NO_ACTION` — допустимый результат `step`. Хосту нужно действие по умолчанию.
- Сон: `agent.sleep(cycles=3, sleep_duration_seconds=0.0)` по расписанию хоста.
- В тестах включать `NOWA_STRICT_LEARNING=1`: запись в устойчивую память днём даст исключение.

### Как это сделано в NOWA Sea (`nowasea/brains/nowa_adapter.py`)

- **Создание** идёт через `agent_factory.AgentFactory(AgentConfig(actions, hippocampus_capacity, cortex_capacity))
  .spawn(genome, epigenome, rng)`: фабрика применяет гены к модулям и ставит `MortalitySystem`.
- **Ловушка:** фабрика создаёт `Agent` без `PlasticityConfig(expected_wake_interval_s)`, и ядро берёт 3600 с.
  Исправление: задать `agent.plasticity.expected_wake_interval_s = T` и пересобрать ещё пустой лабильный слой
  `agent.labile = LabileLayer(agent.plasticity)` (тот же объект передать в `sleep_manager.labile`/`.plasticity`).
- **Одно решение** — три вызова:
  1. `advance_time(elapsed)`;
  2. `commit_executed_transition(prev_action, reward, context_events=prev_tokens, decided_action=…, overridden=…)`
     без `dt`;
  3. `step(tokens, decision_only=True, dt=0.0)`.

  `dt=0.0` допустим: настенные часы ядро берёт только при `dt=None`.
- **Потомок:** геном — `GenomeVector.from_dict(a).crossover(from_dict(b), mode="uniform", rng)` → `.mutate(rate)`.
  Эпигеном родителя даёт `factory.extract_epigenome(agent)`, смешивание — `EpigenomeSnapshot.blend`. Родители могут
  жить в разных процессах, поэтому геномы и эпигеномы ходят словарями (`to_dict`/`from_dict`), а потомок
  создаётся там, где будет жить.
- **Загрузка:** сначала `factory.spawn(genome)` (геном берётся из host-состояния — в `.nowa` его нет), затем
  `AgentStorage.load_agent(..., все компоненты)`, затем вернуть `agent.epigenome`.

## 3. Два уровня поведения

- **NOWA:** намерение («кормиться», «бежать», «прятаться», «спать»…).
- **Моторный слой хоста:** непрерывное исполнение — руление, обход препятствий, стайные силы, рывок, путь
  к укрытию. Тут же хост переопределяет решение, если тело не может его выполнить (флаг `overridden`).
- **Награда** считается из физиологии тела: энергия, урон, выносливость, безопасность. Так делает демо-колония.
  Хорошая награда — приращение состояния тела за тик, а не оценка «правильности» действия.

## 4. Сенсоры → токены

- Токены — строки вида `признак:уровень`. Нужен **грубый и ограниченный словарь**: 3 уровня, 6–9 признаков на вид.
  Размер словаря напрямую определяет рост памяти и стоимость шага (раздел 5).
- Восприятие с перекрытием (прямая видимость, укрытия) считается в хосте. В токены попадает только то, что
  существо действительно видит.
- **Решения по событию:** решать, когда изменился набор токенов, но не чаще `t_min` и не реже `t_max`.
  Срочные события (появилась угроза) запускают решение сразу. Это главный рычаг производительности.

## 5. Бюджет производительности

| Что | Значение |
|---|---|
| Решение (step + commit), память пустая | ~2 мс |
| То же, гиппокамп 1024 заполнен | 7–9 мс |
| То же, после 12 000 решений (гиппокамп 256) | до 17 мс — рост продолжается |
| Сон 3 цикла | 0,8–2,8 с, растёт с возрастом |
| `imagination_enabled=False` | на стоимость не влияет |
| Пропускная способность i7-12700H | 1 процесс — 95 решений/с; 8 — 566; 16 — 638 |
| Тело демо-колонии сверху ядра | ~4,6–5 мс на агента при пустой памяти |

- Цена агента растёт с возрастом **без предела**. При заполненном гиппокампе продолжают линейно расти
  `temporal_chains` (168 → 882 КБ за 1500 → 6000 решений) и `visit_counts`.
  - Код это подтверждает: `ChainMemory` (`src/temporal_chains.py`) не имеет ни ёмкости, ни прореживания. Цепочки
    находит сон из последних эпизодов гиппокампа (`SleepManager`, «Create/update TemporalChains»).
  - Поэтому в долгоживущем мире нужны конечная жизнь или смена поколений и грубый словарь.
- Масштаб опытов автора меньше нашего. По аннотации на alphaXiv: колонии из 4, 12 и 24 основателей, горизонт
  около 6000 единиц времени, не больше 90 минут реального времени на прогон. В текущей версии кода смертей от
  старости не было: горизонт короче минимальной жизни. 60 агентов и многочасовые прогоны автор не проверял,
  долгий режим текущего кода никем не измерен.
- Оценка бюджета: `агенты × решений_в_сек_симуляции × скорость × стоимость_решения ≤ пропускная_способность`,
  плюс сон `агенты × стоимость_сна / период_сна`.
- Пример: 60 агентов, решение раз в 2 с, 10x, 9 мс → 2,7 с CPU в секунду, то есть 3–4 процесса из ~8 полезных.
- Агенты независимы, поэтому **шардировать по процессам** легко. Между процессами ходят только токены, награды
  и действия. Сон выполнять в шарде вне тика симуляции. Масштабирование упирается в число производительных ядер.

### Пул процессов (`nowasea/brains/pool.py`)

- Мозги независимы и раскладываются по процессам (`spawn`-контекст, по трубе на процесс). Между процессами ходят только
  токены, награды и намерения пакетами. Ответы забираются без блокировки, хост продолжает исполнять старое намерение.
- **Сон** — в отдельном потоке внутри процесса-шарда. Так сон одного мозга (0,3–2,5 с) не останавливает решения
  остальных: GIL переключает потоки. На мозг стоит замок, во время сна запросы к нему отвечаются «пропущено».
- **Торможение мира:** если самому старому неотвеченному решению больше 1,5 с *симуляции* (стена × скорость),
  шаги ждут. Достигнутая скорость честно падает, а не копится отставание решений.
- **Замер в живом хосте** (i7-12700H, 2 процесса, ~20–35 агентов, 10x, 8–12 минут, ~1,5–2 ч симуляции):

  | Ёмкость гиппокампа | p50 решения | p95 (среднее / максимум) | Скорость | Память процесса мозгов |
  |---|---|---|---|---|
  | 256 | 9,0 мс | 16,9 / 23 мс | 9,6x | плато ~92 МБ |
  | 128 | 6,5 мс | 9,4 / 12 мс | 9,7x | плато ~87 МБ |

  Ёмкость — главный рычаг стоимости, поэтому в аквариуме по умолчанию 128. Цена — более короткая эпизодическая
  память. Влияние на качество обучения не измерено. Время решения включает ожидание GIL, пока в том же процессе
  идёт сон другого мозга: пики p95 отчасти от этого.

### Пищевая экология и NOWA

- Сытость нужно ограничивать в теле, а не надеяться на обучение. Сытый хищник не видит добычу (токен
  `prey:none`, пока энергия выше порога вида и не кончилось переваривание). Иначе в первые полчаса хищники
  выедают всех, и обучаться некому.
- Удар — отдельная попытка с перезарядкой 2 с и вероятностью (рывок, бегство жертвы, укрытие, плотная стая
  снижают шанс). Нельзя ловить «за контакт в каждом шаге».
- **Побуждения тела** передавать через `physiological_bias` (словарь «действие → давление»), как это делает
  демо-колония для голода и сна. Голод тянет к кормовому действию вида, страх — к бегству и укрытию, усталость —
  к отдыху, видимая добыча — к броску. Это мягкое давление: мозг может его перебить. Без побуждений необученный мозг
  выбирает кормление не чаще прочих действий, и донные падальщики вымирали от голода раньше, чем успевали чему-то
  научиться.
- **Устойчивость сообщества нельзя доверять обучению.** Нужны обратные связи, которые действуют при любой политике:
  - редкую добычу трудно поймать (функциональный отклик III типа);
  - хищник размножается только при достаточной кормовой базе;
  - плодовитость падает у потолка численности;
  - пастбищная рыба сыта — не ест;
  - укрытие почти полностью защищает.

  Без них полный состав за 1–1,5 ч симуляции проваливался в бум и крах.

### Награда должна зависеть от действия (стенд `python -m nowasea.tools.learnbench`)

Стенд: на каждом решении контекст — угроза (`threat:near`) или спокойствие. При угрозе уклонение (`flee`/`hide`)
даёт +R, остальное −R. Ниже — доля уклонений при угрозе по блокам по 150 решений, 2 сида, 7 действий
(случайный выбор даёт ≈ 0,29).

| Настройка | Начало → конец |
|---|---|
| R = 0,5, без сна | 0,65 → 0,97–1,0 уже через 300 решений |
| R = 0,5, сон (3 цикла) каждые 200 решений | 0,64 → 0,84 → 0,73 |
| R = 0,1, сон каждые 200 | 0,36 → 0,81 |
| R = 0,5, сон каждые 200, `physiological_bias` 0,6 на уклонение | 0,66 → 0,96 → 0,90 |

Выводы:
- **Ядро учится быстро, если последствие зависит от действия и приходит сразу.** В аквариуме сначала было не так:
  штраф «рядом хищник» начислялся одинаково при любом выборе, и в живом мире NOWA уклонялась при угрозе лишь в 45 %
  случаев. У рефлекса без обучения было 100 %, у случайного выбора 29 %. Решение — награды за то, что сделано:
  - жертве — за прирост дистанции до видимого хищника и за уход в укрытие, сильный минус за бросок хищника;
  - хищнику — за сближение с добычей;
  - штраф за само присутствие угрозы — слабый.
- **Сон частично стирает лабильно выученное:** после консолидаций доля верных выборов снижается с 0,84 до 0,73.
  Это поведение ядра, а не хоста. Стоит обсудить с автором NOWA (переносится ли лабильный слой в устойчивый целиком,
  не «съедает» ли выученное синаптическая гомеостазия).
- **Число признаков в контексте решает всё.** Тот же стенд с дополнительными нерелевантными признаками (по 3 уровня),
  без сна, R = 0,5:

  | Признаков в контексте | Доля уклонений: начало → конец |
  |---|---|
  | 4 | 0,65 → 1,0 |
  | 6 | 0,25 → 0,92 |
  | 9 | 0,28 → 0,26 — обучения нет |

  NOWA различает ситуации по набору токенов. При 9 признаках почти каждая ситуация новая, и опыт не переносится.
  Хост должен подавать **2–3 значимых токена** по ситуации: угроза → «угроза, укрытие, выносливость»; добыча →
  «добыча, выносливость, энергия»; голод → «энергия, корм»; иначе — «корм или стая, свет». Так в аквариуме
  (`Simulation._salient`). Полный набор ощущений хранится отдельно для интерфейса. У автора в примерах контекст —
  события вида `context:forage`, `event:found_hay`, а не вектор состояния.
- **Что из статьи автора важно для хоста** (habr.com/ru/articles/1095790):
  - награда — немедленный скаляр заметной величины (+0,85 за найденное сено);
  - ночью эпизоды с |δ| < 0,12 отбрасываются, бюджет повтора — 32 эпизода за ночь, приоритет — |δ|;
  - кредит раздаётся по цепочке до 6 шагов назад (λ = 0,85).

  Мелкие «размазанные» награды по 0,01–0,1 до консолидации не доживают: значимые последствия нужно давать событием.
- **Живой аквариум** (`--scale 0.5`, ~2,2 ч симуляции, сид 11, одинаковые миры; `nowasea.tools.soak`):

  | Искорки | NOWA, 9 признаков | NOWA, внимание (3 токена) | + инстинкты ×1,6 | Рефлекс | Случайный |
  |---|---|---|---|---|---|
  | Уклоняется при угрозе рядом | 43–45 % | 55 % | 61 % | 99 % | 29 % |
  | Съедено среди умерших | 77–89 % | 83 % | 73 % | 82 % | 77 % |
  | Срок жизни, сут. | 1,18–1,23 | 1,41 | 1,31 | 1,49 | 1,48 |

  - NOWA выбирает разумно чаще случайного, а её искорки реже всех гибнут от хищников. По доле «правильных» реакций
    она уступает жёсткому рефлексу.
  - Рост качества выбора по поколениям за ~2 ч симуляции сквозь шум не виден: поколения по 2–14 особей, жизнь
    около 600 решений, 1–2 сна.
  - Физиологическое смещение NOWA учитывает мягко: даже давление 1,0 на «бегство» даёт ~60 % уклонений.
- Без контрольной группы утверждать «NOWA учится» нельзя.
- **Правильная контрольная группа — «замороженная NOWA» в той же воде.** Это то же ядро, те же гены и тот же
  `physiological_bias`, но хост не передаёт награды (`reward=NaN`) и не вызывает консолидацию (`sleep` пропускается).
  Случайный мозг и жёсткий рефлекс для этого не годятся: побуждения тела уже делают необученную NOWA лучше случайной,
  а рефлекс «платит» за ошибки иначе. В аквариуме это `BrainSpec.frozen`, каста наследуется, доля —
  `SimConfig.control_share`.
- **Метрики, которые меряют обучение, а не послушание инстинкту** (`nowasea/ecosystem/insights.py`, разобраны тремя
  независимыми моделями):
  - различение контекста: доля пряток при угрозе с укрытием рядом минус с укрытием далеко; побуждения там одинаковы,
    поэтому без обучения разность нулевая;
  - изменение качества выбора через один сон: 15 решений после минус 15 до, по особи;
  - всё — пластичные против замороженных; единица анализа — особь;
  - решения, где ворота ядра ничего не пропустили (`NO_ACTION`) и тело действовало по инстинкту, из оценки мозга
    исключаются и показываются отдельно.
- **Итог двухчасового прогона приёмки** (полный состав, 18 ч симуляции, 21.11.2026):
  - различение контекста у обучающихся искорок **+0,05 [0,038; 0,063]** на 365 особях, у иглозубов
    +0,03 [0,007; 0,057] на 124 — выше нуля, которого дают инстинкты без обучения;
  - изменение через сон у искорок **−0,11 [−0,13; −0,08]**: сон ухудшает выученное, как на стенде;
  - замороженная каста искорок за 55 поколений вымерла: потомков оставили только обучающиеся. Это отбор в пользу
    обучения, но заодно контроль исчез — для сравнения нужна каста, которую поддерживают вне отбора;
  - укрытие снижает долю поимок с 18 % на открытой воде до 3 %, стая — до 8,5 %.
- **Аффект хоста.** Порядок `commit(prev)` → `step(tokens, dt=elapsed)` обязателен: при `step(dt=0)` после
  `advance_time` аффект всех агентов навсегда нулевой (ядро интегрирует аффект коммита временем предыдущего шага).
  С живым аффектом стресс держится высоко (~0,8), и ворота чаще «замирают» (`NO_ACTION`). В аквариуме есть мозги `reflex` (действует по побуждениям
  тела, без обучения) и `random`. Сравнение — три одинаковых мира через `nowasea.tools.soak --brain nowa|reflex|random`
  и метрики качества выбора из `stats.learning` (`evade`, `feed`, `hunt`).

## 6. Сохранение и загрузка

- Обученного агента сохраняет `storage.AgentStorage(save_dir).save_agent(...)` / `load_agent(...)`.
  Формат — JSON `nowa-agent-state`, расширение `.nowa`; pickle отвергается.
- **Ловушка:** аргумента `agent=` мало. Передавать явно все компоненты: `hippocampus, cortex, selector,
  sleep_manager, agent, neuromodulators, affective_persistence, affective_background, affective_space,
  semantic_emotions, emotional_memory, emotional_expectations, emotional_regulation, conflict_arbitration,
  intent_memory, affect_state`. Иначе теряется медленный аффект: фон, семантические эмоции, эмоциональная память,
  ожидания.
- Проверка round-trip: `learning_guard.stable_payload(a) == stable_payload(b)` по 8 разделам — value_layer,
  visit_counts, intent_strengths, channels, cortex, temporal_chains, strategies, slow_affect. Со всеми
  компонентами совпадают все 8.
- Состояние ГСЧ не сохраняется: поведение после загрузки похоже, но не бит-в-бит.
- Размер: гиппокамп 256 — 3–5 МБ, гиппокамп 1024 — 8,5 МБ JSON; gzip уменьшает в ~12–15 раз.
  Запись занимает 0,2–0,55 с, чтение — 0,1–0,26 с. Сохранять параллельно по шардам и сжимать.
- Штатный сейв демо-колонии (`colony_storage.py`) память NOWA **не хранит**, только геном, аффект и уровни
  нейромодуляторов. Как образец сохранения мозгов он не годится.

## 7. Эволюция

- Геном — `GenomeVector.random(rng)`, `a.crossover(b, mode="uniform", rng=rng)` (возвращает двоих потомков),
  `.mutate(rate=..., rng=rng)`, `.generation`.
- Эпигеном — `EpigenomeSnapshot.extract(cortex_patterns=..., ...)` передаёт потомку ограниченный набор уже
  консолидированных следов.
- В геноме 39 генов в 7 группах: нейромодуляторы 8, аффект 9, бодрствование 4, мотивации и восприятие 8,
  обучение 5, воображение 4, срок жизни 1. Геном настраивает коэффициенты модулей, но не меняет связи между ними.
- Гены тела (скорость, обзор, метаболизм, размер) хост ведёт сам, рядом с геномом NOWA.
- **Срок жизни:**
  - в ядре есть `mortality.MortalitySystem(max_lifespan_steps=..., max_lifespan_age_s=...)` с `update`,
    `get_age_fraction` и `to_dict`/`from_dict`;
  - ген `lt_max_lifespan_factor` (0,5–2,0, по умолчанию 1,0) — множитель максимальной жизни;
  - хосту удобно задавать базовый срок вида и умножать его на ген.

  По препринту старость сопровождается насыщением кортизола, ростом стресса и отрицательной валентностью,
  а смерть от старости отделена от голода.
- *Не проверено:* как демо-колония применяет геном к новому агенту (`AgentFactory`, `_apply_saved_genome`) —
  разобрать при реализации размножения.

## 8. Лицензия и подключение

- PolyForm Strict 1.0.0: только некоммерческое использование. Распространять, изменять и делать производные
  работы без разрешения автора нельзя.
- Не копировать код в свой репозиторий. Установочный скрипт клонирует NOWA на коммите из lock-файла в папку
  под `.gitignore`.
- Весь доступ к ядру — через один модуль-адаптер. Ловушки этого документа живут в нём.
- Обновление — скриптом с проверкой совместимости: смоук хоста, round-trip по `stable_payload`, замер решения и
  сна против базовой линии. При провале остаётся старый коммит.
- Перед публикацией проекта согласовать использование с автором.

## 9. Чек-лист нового мира

1. Виды → каналы действий → словарь токенов (грубый, ограниченный).
2. Моторный слой: как каждое намерение исполняется телом, когда хост переопределяет решение.
3. Награда из физиологии тела.
4. Время: единица `dt`, `expected_wake_interval_s`, расписание сна (день и ночь).
5. Частота решений: `t_min`, `t_max`, срочные триггеры.
6. Бюджет по формуле раздела 5 на целевой машине, срок жизни под p95 стоимости решения.
7. Шардирование и где выполняется сон.
8. Сейв через адаптер со всеми компонентами, проверка `stable_payload`.
9. Размножение: геном, эпигеном, гены тела, поколение, родословная.
10. Подключение NOWA скриптом, lock-файл, проверка совместимости при обновлении.

## 10. Открытые вопросы

- **Цена обдумывающего режима (`DELIBERATIVE`).** По препринту его включает арбитр при высокой неопределённости:
  дисперсия TD-ошибки, вероятность ошибки, удивление. Низкая надёжность политики включает его принудительно.
  В нашем прогоне отключение воображения ничего не меняло — видимо, режим не включался. Стоимость шага при высокой
  неопределённости (новичок, смена обстановки) не измерена.
- **Число циклов сна.** Что делает цикл (по препринту): кластеризует эпизоды, закрепляет паттерны коры, проигрывает
  TD-реплей с ограниченным бюджетом, переносит лабильные метки в устойчивые веса, находит временные цепочки,
  ослабляет неиспользуемые привычки, восстанавливает Process S. Как число циклов влияет на качество обучения
  и где минимум — неизвестно.
- **Рост `temporal_chains`.** Ограничителя в ядре нет (проверено по коду). Без правки ядра доступны только
  косвенные рычаги: срок жизни, грубый словарь, реже сон. Проверить, уменьшает ли рост меньший гиппокамп.
